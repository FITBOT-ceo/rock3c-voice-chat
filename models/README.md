# Voice Chat Models

이 폴더는 Rock 3C 음성 대화 실험에서 사용하는 모델 파일을 위한 위치다.

현재 기본 운영 경로는 Groq API 기반이므로, 이 폴더는 주로 로컬 실험용 모델 메모를 위한 위치로 본다.

예상 대상:

- Qwen2.5 GGUF
- Vosk 모델
- whisper.cpp 모델
- Piper voice 모델

원칙:

- 기본 운영에 필요한 Groq 원격 모델은 이 폴더에 두지 않는다.
- `edge-tts`는 원격/패키지 기반이므로 별도 모델 파일이 없다.
- 락카키 시스템 모델과 섞지 않는다.
- 대용량 파일은 Git에 직접 넣지 않는다.
- 파일명, 출처, 체크섬은 별도 메모로 남긴다.
